WEBSITE UCAPAN WISUDA — PUTIH & EMAS

FILE UTAMA
- index.html : seluruh HTML, CSS, dan JavaScript sudah ada di satu file.
- images/foto1.jpg sampai images/foto6.jpg : ganti dengan foto pribadi (nama file harus persis sama).
- music.mp3 : tambahkan file musik MP3 yang kamu punya hak untuk digunakan. Jika file ini belum ada, fitur musik akan memberi pemberitahuan.

CARA MENGUBAH TEKS
Buka index.html di editor teks/kode, lalu cari teks seperti:
- Happy / Graduation!
- 11 November 2026
- Dear, you
- isi surat dan isi kejutan
Edit teksnya lalu simpan. Kamu boleh menghapus tanggal jika tidak diperlukan.

CARA MENAMBAHKAN FOTO
1. Buat folder bernama images.
2. Masukkan foto ke folder itu dan beri nama foto1.jpg, foto2.jpg, ... foto6.jpg.
3. Jika foto PNG, ubah nama referensi di index.html menjadi .png juga.
4. Jangan gunakan foto orang lain tanpa izin.

CARA MENAMBAHKAN MUSIK
Taruh file MP3 bernama music.mp3 di folder yang sama dengan index.html. Browser HP tidak mengizinkan autoplay musik sebelum pengguna mengetuk tombol; ini normal.
Gunakan musik yang kamu buat sendiri atau yang lisensinya mengizinkan penggunaan tersebut.

PUBLISH GRATIS DI GITHUB PAGES (HP ANDROID)
1. Buka https://github.com/ dan buat akun/login.
2. Buat repository baru bernama wisuda-spesial. Pilih Public.
3. Unggah index.html, folder images berisi foto, dan music.mp3 (jika ada). Pastikan index.html berada di root repository, bukan di dalam subfolder lain.
4. Buka Settings > Pages.
5. Di bagian Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Tunggu beberapa menit. Alamat biasanya berbentuk https://USERNAME.github.io/wisuda-spesial/.
8. Buka tautan itu di browser HP dan tes semua foto, tombol kejutan, serta musik.

CATATAN
- Hosting GitHub Pages gratis untuk website statis publik; jangan unggah informasi pribadi atau rahasia.
- Jika mengedit file lewat GitHub di browser HP, buka file index.html, pilih ikon pensil/Edit, simpan dengan Commit changes.
- Untuk mengunggah foto, gunakan Add file > Upload files. Bila upload folder sulit di HP, unggah file gambar satu per satu; buat folder images dengan memasukkan path images/foto1.jpg saat membuat/mengunggah file bila antarmuka mendukung, atau unggah ZIP dan ekstrak di perangkat lalu unggah file-file tersebut.
